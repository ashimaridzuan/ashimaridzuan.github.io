Problem Statement

Existing KBs has limitations in covering every suppport scenario, troubleshooting guide and "how-to" procedure. As a result, L1 analyst often need to search across multiple sources to find the right answer, which can be time-consuming and inconsistent.

Solution

This project uses Microsoft Copilot to build a conversational support assistant that understands intent in two languages, retrieves verified knowledge sources, and gives concise, helpful answers. The agent is designed for L1 analyst interaction, troubleshooting, and guided how-to advice.
