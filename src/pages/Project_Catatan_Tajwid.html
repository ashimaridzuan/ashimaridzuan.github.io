Why I Built This

Learning Tajwid rules often means digging through dense Arabic text scattered across books and websites with no consistent structure. I wanted a clean, modern reference that I'd actually enjoy using myself — something that feels closer to a study app than a scanned textbook. As someone learning alongside building, this project let me combine two things I care about: improving my own Tajwid and practising front-end development.

Design Decisions

The layout is intentionally minimal so Arabic text is easy to read without visual clutter. Each rule lives in its own card, making the content feel self-contained and scannable rather than overwhelming. Dark mode was built in from the beginning — a lot of Quran reading and study happens at night, and straining against a bright white screen felt like the wrong experience.

The quiz mechanic was kept deliberately simple: read the rule, answer a question, move on. No timers, no penalties — just reinforcement. The progress tracker uses localStorage so your progress persists between sessions without needing any backend or login.

Challenges

  • Bilingual layout: Structuring Arabic text alongside English explanations without it feeling misaligned or awkward required careful CSS handling of right-to-left text direction within a left-to-right layout.
  • Client-side quiz logic: Building a quiz system that works entirely without a backend meant managing all state in JavaScript and making sure question randomisation felt fair.
  • Persistent progress: The progress tracker needed to remember what you'd studied between visits — solved using localStorage with a simple key-value structure per rule.

Thinking Behind It

This is a passion project. I wanted to prove to myself that I could build something fully functional from scratch — from content architecture to front-end logic — and that learning tools don't have to be dry or boring. Islamic education deserves the same level of thoughtful UX that goes into any other learning platform, and this is my small step toward that.

Turning information into organized experiences through both design and code.
